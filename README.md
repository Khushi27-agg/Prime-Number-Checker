# Day 05 – Prime Number Check (Java)

This program checks whether a given number is a **prime number** using basic control flow and loop logic in Java.

## Concepts Used
- Loops
- Conditional statements
- User input handling
- Mathematical logic

## Logic Used
A number is considered prime if:
- It is greater than 1  
- It has no divisors other than 1 and itself  

The program checks divisibility from 2 up to the square root of the number to improve efficiency.

## Example
Input: 29
Output: 29 is a prime number.
